# Film Meter Log

필름 카메라용 웹 노출계 + 촬영 기록장. 폰 카메라로 측광하고, 찍은 컷마다 노출값·위치·시각을 기록해 두었다가 롤이 끝나면 JSON/CSV로 내보냅니다. 내보낸 파일은 나중에 스캔본에 EXIF/GPS 메타데이터를 입히는 데 씁니다.

**바로 열기:** https://egtntwth.github.io/light_meter/

## 기능

- **롤 설정**: 포맷(135, 하프프레임, 120 6×4.5~6×9, 110, 4×5, 8×10) 선택 시 컷 수 자동 입력, 필름·박스 ISO·EI(푸시/풀 표시), 롤 번호 자동 증가, 카메라·렌즈, 프리셋 저장
- **측광**: 실시간 카메라 피드, 터치 스팟 / 중앙중점 / 평균 측광, 조리개 우선·셔터 우선, 1스톱·1/3스톱 단계, 하이라이트 포화 경고
- **프로그램 시프트**: 리드아웃을 좌우로 드래그하면 같은 EV에서 조리개·셔터 조합만 변경, 두 번 탭하면 초기화
- **촬영 기록**: 셔터 → "사진 찍었나요?" → 실제 사용값 확인 후 위치·시각과 함께 저장, 안 찍었으면 건너뛰기
- **컷 카운터**: `1/36` 형식, 정해진 컷 수를 넘으면 빨간색 경고
- **다중노출(ME)**: 같은 컷에 여러 노출 기록, 횟수 계획(2~6회/자유), 노출당 자동 보정(−log₂ n EV)
- **롤 종료 / 내보내기**: 컷 목록 확인·삭제, JSON(컷 단위로 묶음)·CSV 내보내기, 모바일 공유
- **언어**: 한국어 / English

## 측광 방식

장면의 밝기(EV₁₀₀)는 다음과 같이 계산합니다.

```
EV100 = log2(N² / t) − log2(ISO / 100) + log2(측광 영역 휘도 / 0.18) + 보정값
```

- `N`: 폰 렌즈 조리개(설정에서 입력), `t`, `ISO`: 폰 카메라가 실제로 쓴 노출값
- 휘도는 sRGB 감마를 풀고 `0.2126R + 0.7152G + 0.0722B`로 계산, 18% 중간회색 기준

| 플랫폼 | 노출 정보 제공 | 방식 |
|---|---|---|
| Android Chrome | `MediaStreamTrack.getSettings()`로 노출시간·ISO 제공 | 절대 측광 |
| iPhone Safari / Chrome | 제공하지 않음 | 기준 노출계로 한 번 보정한 값 사용 |

추천 노출: `t = N² / 2^(EV100 + log2(ISO/100))`를 가장 가까운 표준 셔터/조리개 값으로 맞추고 오차를 ±EV로 표시합니다.

## 실행

서버 없이 `index.html` 하나로 동작합니다. 카메라와 위치 권한은 HTTPS에서만 열리므로 GitHub Pages 주소로 접속하세요. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

기록은 브라우저 저장소(localStorage)에 저장됩니다. 브라우저 데이터를 지우면 사라지니 롤이 끝나면 내보내기를 해 두세요.
